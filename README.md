# Dr. Suárez — Consultor de Diabetes

App web gratuita basada en los libros de Frank Suárez.

## Deploy en GitHub Pages (gratis, 5 minutos)

1. Crea un repositorio en github.com (ej: `dr-suarez-diabetes`)
2. Sube el archivo `index.html` de esta carpeta
3. Ve a Settings → Pages → Source: main branch / root
4. En ~1 minuto tendrás una URL tipo: `https://TU_USUARIO.github.io/dr-suarez-diabetes`
5. Abre esa URL en el celular, ingresa tu API key de OpenRouter y listo
